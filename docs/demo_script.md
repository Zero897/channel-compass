# 旧版C003闭环演示脚本

> 仅保留为自动化回归样例，不用于最终企业版主展示。企业版案例见 `judge_cases.md`。

1. 打开“渠道客户”，定位东启科技，展示健康度、库存风险和回款风险。
2. 打开风险事件 R010，展示库存覆盖、库龄、销量下降、逾期和信用暴露证据。
3. 触发或展示 AI 风险摘要，强调它只组织证据，不参与评分。
4. 展示自动生成的 T001 处置任务，选择“平衡干预”。
5. 将状态由“待处理”改为“处理中”，再改为“已完成”。
6. 填写结果：“完成客户沟通，安排库存调拨，建议复核额度”。
7. 回到风险事件，说明处置结果后续回流用于阈值和模型校准。

本地可核对 `data/processed/c003_demo_trace.json`；飞书状态切换、AI摘要、通知、截图和录屏必须人工完成。
