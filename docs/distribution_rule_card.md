# 非项目类三表规则卡 v0.1

用途：验证销售、回款、应收三表能否形成客户级风险结果。阈值仅用于仿真联调，必须在企业数据到手后回测和校准。

## 经营下滑风险

- 近4周销售额较此前4周下降10%—20%：黄色；
- 下降超过20%：触发关注；
- 下降超过25%：红色。

## 应收回款风险

普通条件：

- 逾期应收占比超过20%；
- 最大逾期超过30天；
- 近4期应收余额上升超过20%；
- 近4周回款覆盖率低于70%。

命中1—2项为黄色，3项及以上为红色。考虑单项严重程度，逾期应收占比超过50%或最大逾期超过60天时直接判为红色。

## 限制

- 销售与回款使用同一四周窗口只是接入测试口径，没有处理企业真实账期错位；
- 回款覆盖率不是逾期概率，不能单独作为授信依据；
- 企业字段、账期和标签确认前，不报告真实准确率或降损收益。
