# 动态到期管理原型规则卡

## 适用范围

- 常规消费品分销：进入120天风险排序模型和动态到期规则。
- 企业级项目类：保留在动态监控中，但不进入统一回款模型；实际应按合同里程碑、交付和验收节点一单一议。

## 分层规则

| 阶段 | 原型建议动作 | 是否自动执行 |
|---|---|---|
| 到期前5天 | 提醒付款并确认回款计划 | 否 |
| 超期1—30天 | 电话及邮件催款 | 否 |
| 超期31—60天 | 建议正式发函并升级复核 | 否 |
| 超期61—120天 | 建议进入停止发货审批 | 否 |
| 超期120天以上 | 建议进入法务及诉讼可行性复核 | 否 |

客户历史迟付率达到20%或当前逾期占比达到50%时，原型标记为“履约较差”；其发生超期后建议同步进入停止发货审批。该阈值只用于入围赛演示，不代表企业正式制度。

## 模型与规则分工

- 逻辑回归：在订单尚未形成成熟结果时进行120天超期风险排序。
- 动态规则：历史回放以应收快照日为计算基准；业务模式先检查数据新鲜度，超过阈值时停止当前阶段判断并要求刷新数据。
- 大模型：解释证据、生成简报和人工核查建议。
- 业务人员：审批授信、停发、催收升级和法务动作。
