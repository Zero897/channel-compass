# 渠智罗盘最终交付清单

## 1. 协作者可运行包

- 文件：`dist/渠智罗盘_协作者可运行包_20260813.zip`
- 用途：仅限参赛团队内部协作与演示。
- 包含：项目代码、冻结模型、企业提供的脱敏模拟数据、11张飞书结果表、文档与测试。
- 不包含：真实`.env`、飞书密钥、后端触发令牌和实际人工反馈文件。
- 首次运行：阅读`docs/协作者运行说明.md`，安装`requirements-all.txt`后执行冻结模型推理。

```powershell
python -m venv .venv
& ".\.venv\Scripts\python.exe" -m pip install -r requirements-all.txt
& ".\.venv\Scripts\python.exe" "src\run_frozen_company_pipeline.py"
```

需要连接飞书时，将`.env.example`复制为`.env`，真实凭据通过安全渠道单独发送，不要写入压缩包或聊天记录。

## 2. 比赛提交包

- 文件：`dist/渠智罗盘_比赛提交包_20260813.zip`
- 用途：比赛平台上传与评委离线查看。
- 包含：项目代码、冻结模型、模型与数据审计证据、11张飞书结果表、便携演示、方案文档和公开测试。
- 不包含：企业原始数据、真实密钥、人工反馈、大规模训练特征和订单级预测明细。
- 无企业原始数据时可运行便携演示：

```powershell
python -m venv .venv
& ".\.venv\Scripts\python.exe" -m pip install -r requirements-all.txt
& ".\.venv\Scripts\python.exe" "src\run_portable_demo.py"
```

## 3. GitHub公开仓库

- 仓库：`https://github.com/Zero897/channel-compass`
- 公开内容：源代码、配置模板、合成/模拟样例、文档和测试。
- 由`.gitignore`排除：企业原始数据、模型二进制、生成报告、飞书导出、`.env`、临时运行日志和交付压缩包。

## 4. 交付前验证

```powershell
& ".\.venv\Scripts\python.exe" -m compileall -q src tests
& ".\.venv\Scripts\python.exe" -m unittest discover -s tests -v
```

压缩包还需满足：ZIP完整性通过、协作者包可在全新目录运行便携演示与冻结模型企业推理、比赛包的公开测试通过、两个包均不含真实凭据。最终文件大小与SHA256以交付消息为准。

## 5. 运行边界

- 飞书“运行分析”调用冻结模型推理，不会在每次点击时重新训练模型。
- 重训入口`src/run_company_pipeline.py`仅供管理员在数据口径或模型版本需要更新时使用。
- Python按稳定编号增量同步11张业务结果表，运行控制表由任务管理器单独回写。
- Python不得覆盖人工处置、审批、执行、负责人、AI摘要、按钮、公式与关联字段。
- 最终授信、停发、催收升级和法务动作必须由业务人员审批。
