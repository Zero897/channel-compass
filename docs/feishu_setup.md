# 企业版飞书实施说明

本说明用于将渠智罗盘的企业数据产物导入飞书多维表格。Python 是处置任务的唯一创建者；飞书只负责关联、分派、AI解释、通知、审批和状态回写，禁止再次创建任务，以免重复。

## 一、导入十一张正式表

按下列顺序导入 `data/exports/feishu/`：

| 顺序 | 文件 | 主字段/外部键 |
|---|---|---|
| 1 | 企业渠道客户.csv | 客户主键 |
| 2 | 企业风险事件.csv | 事件编号 |
| 3 | 企业处置任务.csv | 任务编号 |
| 4 | 企业订单证据.csv | 订单证据编号 |
| 5 | 企业处置情景.csv | 方案编号 |
| 6 | 企业风险处置时间线.csv | 过程事件编号 |
| 7 | 企业库存风险汇总.csv | 库存汇总编号 |
| 8 | 企业库存风险.csv | 库存对象编号 |
| 9 | 企业模型指标.csv | 指标编号 |
| 10 | 企业动态回款监控.csv | 动态监控编号 |
| 11 | 企业客户商品风险暴露.csv | 采购暴露编号 |

导入更新数据时按上述文本键匹配，不用日期、名称或行号作为主键。`demo_output/企业处置任务_演示记录.csv` 仅用于答辩演示，不导入正式任务表。

## 二、建立关联

1. 企业风险事件 → 企业渠道客户：按客户编号关联，多条事件对应一个客户。
2. 企业处置任务 → 企业风险事件：按风险事件编号关联；当前红色事件通常一条任务对应一条事件。
3. 企业订单证据 → 企业风险事件：按风险事件编号关联，多条订单证据对应一个预测事件。
4. 企业处置情景 → 企业渠道客户：按客户编号关联，每个候选客户三种情景。
5. 企业风险处置时间线 → 企业风险事件：按风险事件编号关联。
6. 企业风险处置时间线 → 企业处置任务：按关联任务编号关联。
7. 企业动态回款监控 → 企业渠道客户：按客户编号关联。
8. 企业客户商品风险暴露 → 企业渠道客户：按客户编号关联；按物料编码与库存风险交叉核验，不宣称客户持有库存。

库存表的对象是 SKU—仓库，不归因到渠道客户。库存汇总与明细可先通过仪表盘的产品线、库存组织、风险等级筛选联动，无需强行建立实体关联。

## 三、字段类型与枚举

- 客户编号、事件编号、任务编号及各表主键：单行文本。
- 负责人：人员字段；未分配时保持为空，不写“待分配”。
- 建议负责人角色：单行文本，仅用于提示应由哪类岗位承接；实际负责人仍由飞书人员字段映射。
- 风险分：数字，范围0—100；作为主界面排序指标。
- 模型概率：数字，仅在审计视图展示，不解释为精确违约率。
- 审批状态：待审批、已批准、已驳回。
- 执行状态：待处理、处理中、已完成、已关闭。
- 预警有效性：待确认、有效、部分有效、误报。

人工处置方案、负责人、审批状态、执行状态、完成时间、执行结果、预警有效性由业务人员维护；AI建议动作不能替代人工方案。

## 四、AI风险摘要

在企业风险事件表增加或使用“AI风险摘要”字段，提示词如下：

```text
你是ICT渠道经营风险分析助手。仅依据本条记录中的风险类型、风险等级、关键指标、风险金额、客户历史摘要和规则解释生成风险摘要，不得补充记录中不存在的事实。

请在120字以内输出：
1. 风险结论；
2. 两项最关键证据；
3. 下一步人工核查动作；
4. 若证据不足，明确写“需人工复核”。

不要直接决定信用额度、停供或催收措施，不要宣称客户一定违约，不把模型概率解释为精确违约率。
```

## 五、自动化配置

每条自动化都加入“目标字段为空”或“通知状态未发送”等幂等条件，避免重复触发。

### 1. 事件关联客户

- 触发：风险事件新增或客户编号变化。
- 条件：关联客户为空且客户编号不为空。
- 动作：在企业渠道客户中查找相同客户编号并更新关联客户。

### 2. 生成AI摘要

- 触发：风险事件新增或关键指标更新。
- 条件：风险等级=红色、处理状态=待处理、AI风险摘要为空。
- 动作：按上述提示词生成并写回AI风险摘要。

### 3. 任务关联与分派

- 触发：处置任务新增或风险事件编号变化。
- 条件：关联风险事件为空。
- 动作：查找相同事件编号，写入关联；再按团队规则填写负责人。
- 禁止动作：创建新处置任务。任务已经由Python按稳定编号生成。

### 4. 高风险通知

- 触发：红色事件摘要生成完成。
- 条件：处理状态=待处理且通知状态≠已发送。
- 动作：向负责人发送消息，成功后将通知状态改为已发送。

```text
【渠智罗盘高风险预警】
客户：{{客户名称}}
风险：{{风险类型}} / {{风险等级}}
影响金额：{{风险金额}}
证据：{{关键指标}}
AI摘要：{{AI风险摘要}}
请在 {{截止日期}} 前完成人工复核并更新任务状态。
```

### 5. 分级审批

- 触发：任务进入待审批。
- 动作：按展示用分层规则提交审批；阈值应标注为原型参数，不冒充企业现行制度。
- 审批结果：通过写“已批准”，退回写“已驳回”；飞书不自动调整授信或停供。

### 6. SLA提醒

- 触发：每天09:00。
- 条件：执行状态为待处理或处理中，且距截止日期不超过1天或已经超期。
- 动作：提醒负责人并更新SLA状态。

### 7. 完成与反馈回流

- 触发：任务执行状态变为已完成。
- 条件：执行结果不为空。
- 动作：将关联风险事件处理状态更新为已完成，并提醒填写预警有效性；不自动填“有效”。

### 8. 每日风险摘要

- 触发：每天17:00。
- 动作：汇总红色待处理、超期任务和当日完成任务，发送给团队群。

## 六、建议视图和仪表盘

- 红色风险待处理：按风险金额降序，显示风险分、关键证据、风险加权应收暴露和负责人，隐藏模型概率。
- 我的处置任务：负责人=当前用户，执行状态≠已完成，按截止日期升序。
- 已完成及反馈：显示人工处置方案、执行结果、预警有效性。
- 订单证据审计：仅供展开查看订单贡献、模型概率和原始证据。
- 库存风险：按产品线、库存组织和风险等级筛选，汇总表展示全量口径，明细表只展示Top500。
- 动态到期看板：按业务类型和到期阶段分组，重点展示到期前5天、超期阶段、履约等级及建议动作。
- 五维健康诊断：展示五个分项、综合健康度和下钻证据，不把分数解释为精确违约概率。
- 双风险联动：展示客户近180天采购高库存风险商品的金额和占比，并标注“采购暴露”。

以上飞书操作依赖团队账号权限，必须由团队成员在多维表格中人工配置并截图验收；本地程序不宣称已通过飞书API完成配置。
