# 渠智罗盘产品定位

## 它解决什么问题

渠智罗盘是一个面向ICT分销的“库存—回款”双风险监测与处置闭环原型，不是单纯的AI文本生成器。它将销售、回款、应收和库存等分散数据统一到客户或SKU—仓库对象与观察时点，形成可复现的风险评分、证据和人工任务。

系统承担：

1. 数据关联与质量检查；
2. 订单风险分位与当前有应收余额客户的红黄绿分层；
3. 规则或模型风险识别；
4. 风险证据和影响金额输出；
5. 处置任务、责任人、期限和状态跟踪；
6. 通过稳定任务ID、反馈模板或飞书导出文件保留人工处置结果；未导入反馈时不宣称闭环已经完成。

库存风险是独立的SKU—仓库模块，不与客户风险强行关联。处置策略包含低/基准/高敏感性、资金占用、执行成本和收入机会影响，但仍是透明What-if，不代表因果效果，也不自动决定授信或停供。当前数据没有严格客户级首次逾期前预警样例，答辩主线聚焦存量风险向新增订单扩散监测。

## 飞书 AI 承担什么

飞书 AI 只接收渠智罗盘输出的风险类型、等级、关键指标、金额和客户历史摘要，将结构化结果转成自然语言摘要和建议动作。它不负责计算指标、判定逾期、预测风险、决定授信或验证数据真实性。

```text
企业数据 → 渠智罗盘计算和识别 → 飞书AI解释 → 人工决策 → 处置反馈
```

一句话：渠智罗盘负责发现和管理风险，飞书 AI 负责把风险讲清楚，飞书多维表格负责让人把风险处理完。
