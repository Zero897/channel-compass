# 旧版3客户规则模型卡 v0.1

> 本文件描述早期硬编码仿真演示，不是当前企业回款模型。企业模型以 `model_training_report.md` 和 `model_freeze.json` 为准。

## 用途

用仿真数据验证渠道客户健康度、库存风险、回款风险与处置任务的数据链路。该版本不是企业生产模型。

## 五维健康度

| 维度 | 权重 |
|---|---:|
| 营收质量 | 20% |
| 库存健康 | 25% |
| 回款能力 | 25% |
| 信用暴露 | 20% |
| 合作稳定 | 10% |

健康度80—100为绿色、60—79.9为黄色、低于60为红色。最终风险等级同时考虑健康度和库存、回款规则，以最高风险为准。

## 规则

- 库存：覆盖超过8周、平均库龄超过90天、近4周销量较此前4周下降超过20%；命中2项为黄色，3项为红色。
- 回款：逾期金额占比超过20%、按时回款率低于70%、额度使用率超过85%、平均逾期天数上升；命中1—2项为黄色，3项及以上为红色。

## 已知限制

- 权重和阈值是原型业务基线，必须用匿名历史数据重新校准。
- 仿真案例被有意设计为稳健、库存风险和双风险，不应用其识别结果推断真实泛化能力。
- `模型指标.csv` 只记录演示样本验收，不是准确率、召回率或企业收益证明。
- 10条风险事件是3个客户当前快照按业务观察类型展开的演示记录，不是10个相互独立的历史风险样本。
- 大模型只用于摘要和建议，不能改变规则评分，也不能直接授信、拦单或催收。
