# 渠智罗盘协作者运行说明

## 1. 使用范围

协作者包包含赛事提供的脱敏模拟数据，只能在参赛团队内部传递，不得上传GitHub、网盘公开链接或其他公开渠道。压缩包不包含`.env`真实密钥。

## 2. 环境初始化

在解压后的项目根目录执行：

```powershell
python -m venv .venv
& ".\.venv\Scripts\python.exe" -m pip install -r "requirements-all.txt"
```

## 3. 推荐验证顺序

先运行无需企业接口的便携演示：

```powershell
& ".\.venv\Scripts\python.exe" "src\run_portable_demo.py"
```

再使用已冻结模型运行完整企业分析链：

```powershell
& ".\.venv\Scripts\python.exe" "src\run_frozen_company_pipeline.py"
```

该命令会重新审计7张源表、构建特征、加载`models/primary_payment_risk.joblib`推理，并生成11张飞书业务结果表；不会重新训练模型。

## 4. 连接飞书

复制环境模板：

```powershell
Copy-Item ".env.example" ".env"
```

通过团队安全渠道取得并填写`FEISHU_APP_ID`、`FEISHU_APP_SECRET`、`FEISHU_APP_TOKEN`和`BACKEND_TRIGGER_TOKEN`，然后把`BACKEND_ALLOW_FEISHU_WRITE`改为`true`。不要在聊天截图或GitHub中公开这些值。

启动后端：

```powershell
& ".\.venv\Scripts\python.exe" "src\backend_api.py"
```

另开窗口启动临时公网隧道：

```powershell
cloudflared tunnel --url http://127.0.0.1:8000
```

飞书HTTP自动化使用`https://随机子域.trycloudflare.com/api/runs`。域名与`/api/runs`之间不能有空格。

## 5. 重新训练边界

日常演示不要运行`run_company_pipeline.py`。只有确定新增成熟标签、需要重新比较模型并冻结新版本时，管理员才执行：

```powershell
& ".\.venv\Scripts\python.exe" "src\run_company_pipeline.py"
```
