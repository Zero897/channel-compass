# 决策支持扩展模块

## SKU—仓库库存健康

库存模块按“物料编码＋库存组织”聚合最新季末库存，结合180天/365天库龄、借物超期、库存覆盖天数和近90天销售变化形成红黄绿风险。数据没有客户字段，因此只在统一驾驶舱并列展示，不能写入客户风险结论。

## 三种处置情景

系统为每个预测客户生成继续原条件履约、缩减50%赊销额度、暂停新增赊销履约三种方案。代表性新增订单金额取该客户高风险开放应收的平均订单金额，风险暴露按“当前风险加权应收＋新增批准金额×最高校准概率”计算。

该模块是透明的What-if计算器，用来帮助业务人员比较暴露与业务机会，不预测客户在某项干预下的真实回款结果，也不自动选择方案。

## 流程事件链与反馈

流程事件链记录订单出库、应收快照、风险预警、处置任务和结果回流。当前任务尚未导入人工反馈，因此报告会显示0条结果回流；这是一项真实状态，不用仿真完成记录替代。

业务人员可使用 `data/feedback/task_feedback_template.csv` 填写采用动作、审批和执行结果，再通过 `import_task_feedback.py` 校验并合并。该方式完成了可运行的文件回流接口，但不声称已经接通飞书API。
